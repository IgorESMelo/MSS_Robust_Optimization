# MSS_Robust_Optimization

This repository contains files related to the 3rd article which composes my PhD thesis in Industrial Engineering. 
The article addresses the elective surgical scheduling problem, considering operating room allocation, postoperative resource availability, and uncertainty in surgical durations and resource requirements. The study proposes a robust mathematical optimization model and a matheuristic approach to support surgical planning while balancing operational efficiency and hospital strategic objectives.

This repository contains:
- Instances used in the computational experiments;
- Mathematical model developed for the surgical scheduling problem;
- Proposed matheuristic for solving the problem.
